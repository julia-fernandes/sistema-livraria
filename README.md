# Sistema de Livraria

Projeto desenvolvido em aula para estudo do uso Spring Boot.

**Objetivo:** Gerenciamento de livros  
**Status:** Pausado 

**Problema:** 
Uma livraria online precisa de um sistema para organizar e controlar seu acervo de livros

◎ O sistema permitirá cadastrar livros com informações como
título, autor, preço e quantidade em estoque, além de
armazenar o ISBN, que é um identificador importante

◎ A aplicação será utilizada para facilitar consultas e
gerenciamento do acervo, utilizando uma API com banco de
dados e um front simples para interação
